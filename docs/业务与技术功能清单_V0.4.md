# 鲁银智能化平台业务与技术功能清单

版本：V0.4｜日期：2026-11-04｜依据：[PRD](鲁银投资智能化平台_PRD_V0.4.md)与[线上语义核验](线上数据与业务语义核验_V0.4.md)。

本清单是可开发、可验收的目标，不是已实现功能声明。数据已具备表示线上已有字段及样本；仍需实现接口、计算、页面及回归。沿用旧功能ID并细化子项；新增能力从F100起。原F001经营总览独立菜单取消；目标达成仅在目标录入后启用；不恢复已删除模块。当前仅一位超级用户，不扩展账号体系。
