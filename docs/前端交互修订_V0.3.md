# 前端交互修订 V0.3

日期：2026-11-04。以用户本轮7项修订覆盖PRD V0.2及开发首版中对应的页面布局与入口约定，原业务计算口径继续有效。

1. 主题报表不再是订单台账。固定模板包括法人销售月报、产品分类、区域销售、每日订单日报；报表画布以多级表头表格和合计为主体，配收入结构饼图及排名柱状图。桌面主体表格区域大于60%，图表与表格共用汇总模型。
2. 名义利润作为分析指标，固定提供产品利润贡献、法人利润对照、区域利润分析。法人对照增加利润率柱状比较。分组缺成本时利润保持不可计算，不以0补齐。
3. 智能问数移出主菜单，所有业务页面提供右下角悬浮入口，打开侧边抽屉，继承当前页面、法人和期间。管理后台保留辅助入口。治理无有效制度证据时不输出合规判断。
4. 取消独立经营总览。经营默认进入主题报表；旧overview和ask路径重定向至报表。
5. 调价列表一行代表一批申请。打开批次可查看所有价格行及整体评估，单行仍独立通过、驳回或补正。批次状态由行状态汇总。新建申请继续支持一次提交多行。评估区采用助手式布局，包含综合结论、近期销售/库存/财务价/历史原件四类证据及审核建议。当前标注演示整理，不声称真实模型调用。
6. 产销建议缩小主页面标题，按尾库、库存销售计划、备货缺口切换。每条建议以信息卡呈现产品、法人、余量/缺口、四项证据、建议和反馈入口。计算依据在抽屉中查看，不以泛问答替代固定建议。
7. 管理功能移至独立/admin后台；业务侧仅顶部齿轮进入。后台独立导航含连接集成和语义建模；正式模式由服务端检查管理员身份，演示模式明确预览。

## 验证

单元测试覆盖原业务规则与新增报表聚合（加权利润率、缺成本、不兼容单位）。端到端覆盖多表头图形布局及导出一致性、悬浮问数、批次内独立审批与刷新持久化、产销卡片、独立后台、原治理流程和移动端。

## 延续边界

本轮只改本地应用与报表导出逻辑，不更改生产ERP或新增云端权限。演示审批仍只保存在当前浏览器；真实模型、多源证据、正式审批持久化及完整期间汇总仍须完成既定联调。XLSX导出有固定多表头样式；本轮未新增PDF导出或在XLSX中嵌入图表。
